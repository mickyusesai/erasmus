# EasyReimburse promo videos

The sources of the promo videos. Each version is a web page that can draw any moment of the
film on request; `render.mjs` takes a screenshot of every frame and ffmpeg turns them into an
MP4. The music and sound effects are generated by the Python scripts in `audio/`.

| Folder | Version | Length |
| --- | --- | --- |
| `a-paper-bird/` | **Paper Bird**: light and playful. A pile of travel paperwork, one ticket folds into the bird, then the product in four steps. | 35.6s |
| `b-numbers/` | **Numbers**: dark, bold kinetic typography. The pain in numbers, "0 spreadsheets", the product in four punches. | 27.1s |
| `c-journey/` | **The Journey**: cinematic map story of one participant travelling from Lisbon to Riga. | 37.2s |
| `shared/` | Engine (`kit.js`), brand colours and fonts (`base.css`), the bird's shapes, icons | |
| `audio/` | Synthesiser (`synth.py`), one score per version (`a.py`, `b.py`, `c.py`), cue-sheet effects (`cues.py`) | |

## Rendering

```bash
npm install                        # GSAP, fonts, icons, map data
python3 -m pip install numpy scipy # for the soundtracks

python3 audio/a.py                 # soundtrack → out/a-paper-bird.wav
node render.mjs video a-paper-bird --fps 60 --crf 21 --audio out/a-paper-bird.wav --out out/promo-A.mp4

node render.mjs still a-paper-bird 3.5,12 --hud    # PNG stills at 3.5s and 12s → out/
node render.mjs sheet a-paper-bird --count 24      # contact sheet with time stamps → out/
```

Needs Node 20+, Playwright with Chromium (`npm i -D playwright && npx playwright install chromium`
if it isn't installed globally), ffmpeg, and ImageMagick for contact sheets.

Options: `--workers 4`, `--from 10 --to 15` (part of the film), `--scale 2` (draws every frame
at 4K before scaling down: sharper, about 7x slower), `--size 3840x2160` (a 4K file).

To watch a version in a browser, serve this folder (`npx serve .`) and open
`/a-paper-bird/?play=1`, or `?t=12.5` for one moment.

## How a version is built

- `index.html` loads the fonts and `scene.js`, which builds the scenes and puts every animation
  on one paused GSAP timeline (`tl`) at absolute times. `mount({ duration })` hands the renderer a
  `seek(t)` function.
- Scene changes sit on a beat grid (A: 108 BPM, B: 124 BPM, C: 84 BPM) so picture and music land together.
- B and C list their sound moments in `cues.json`; `audio/cues.py` turns them into effects.
  A's effects are placed in `audio/a.py` with the same times as the animation.

## Rules for scenes

Every frame must depend on the time only, so frames can be rendered in any order and in parallel.

- Animate only through `tl` (absolute times) or `onFrame(t => …)`.
- No CSS transitions or animations, no `requestAnimationFrame`, no `Date`, no `Math.random()`
  (use `rng(seed)`), no `will-change`, no 3D transforms.
- All text and images must be in the page before `mount()` is called.
- People, organisations and tickets shown are made up. No real airline or rail brands.
- Claims come from the website: "from weeks to minutes", "90% less time spent", "Try for free",
  free trial for up to 10 participants, data stored in the EU.
